Booking Alerts

Email Notifications

When a student submits a booking, an alert will be sent to your email address. This uses EmailJS — a free service that sends emails directly from the browser, no server needed.

Enable Email AlertsSend you an email every time a new booking is made
Sign up free at emailjs.com → Email Services → Add New Service → copy Service ID
In EmailJS → Email Templates → create a template, paste this in the body:

New booking from: {{student_name}}
Email: {{student_email}}
Phone: {{student_phone}}
Plan: {{plan}}
Schedule: {{schedule}}
Payment: {{payment_method}}
In EmailJS → Account → General → Public Key

Firebase Setup

Firestore Rules

Go to console.firebase.google.com → backstage-music → Firestore → Rules, delete everything, and paste:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /bookings/{b}   { allow read, write: if true; }
    match /courses/{c}    { allow read, write: if true; }
    match /siteConfig/{d} { allow read, write: if true; }
  }
}
